# Telegram-бот отбора

Бот работает на чистом Node.js, без npm-пакетов. Нужен Node 18+.

## Настройка

1. Создай бота через `@BotFather` и получи токен.
2. Временно оставь `ADMIN_CHAT_ID` пустым, запусти бота и напиши ему `/id`. Он покажет твой chat id.
3. Скопируй `bot/.env.example` в `bot/.env`.
4. Заполни:

```env
BOT_TOKEN=123456:replace_me
ADMIN_CHAT_ID=123456789
INVITE_LINK=https://t.me/+replace_me
REPORT_TIME=21:00
REAPPLY_DAYS=30
```

## Запуск

```bash
node bot/bot.js
```

## Как работает

- Пользователь пишет `/start`.
- Бот задает 5 вопросов анкеты.
- После ответа на последний вопрос заявка уходит админу.
- Админ нажимает `Принять` или `Отклонить` под заявкой.
- При одобрении пользователь получает ссылку на закрытый канал.

Админ-команды на случай, если кнопки недоступны:

```text
/id
/approve <telegram_id>
/reject <telegram_id>
```

Заявки и статусы хранятся в `bot/data/applications.json`.
